# Sea Limited (NYSE: SE) — Three-Statement Financial Model

## Overview
A fully integrated three-statement financial model (Income Statement, Balance Sheet,
Cash Flow Statement) for Sea Limited covering FY2021A–FY2024A historical data
and FY2025F–FY2026F projections.

## What's Inside
| Sheet | Description |
|---|---|
| Cover | Model overview and navigation guide |
| Assumptions | All model inputs — change here to update whole model |
| Income Statement | Revenue by segment → EBITDA → Net Income |
| Balance Sheet | Assets, Liabilities & Equity |
| Cash Flow | Operating / Investing / Financing + Free Cash Flow |
| KPI Dashboard | Key metrics, margins & ratios FY2021–FY2026 |

## Key Features
- Segment-level revenue forecasting (Garena, Shopee, SeaMoney)
- Fully linked three-statement model with dynamic assumptions
- Sensitivity analysis and scenario planning
- IFRS-aligned financial analysis

## Data Sources
- Sea Limited 20-F Annual Reports (SEC EDGAR)
- Sea Limited Quarterly Earnings Press Releases
